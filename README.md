# BaseIntent AI 🤖⚙️

> **Natural Language to On-Chain Intent Engine for Base Network (Chain ID: 8453)**

BaseIntent AI translates human conversational prompts into structured, execution-ready on-chain transaction payloads on Base.

## 🚀 Key Features
- **Autonomous Intent Parsing**: Converts natural language into JSON payloads.
- **Base Native Integration**: Designed specifically for Base Mainnet ecosystem (Aerodrome, Uniswap v3, Basenames).
- **Zero Overhead**: Built on Next.js App Router and hosted seamlessly on Vercel.

## 🛠 Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Network**: Base Mainnet (8453)
- **Web3 Stack**: Viem & OnchainKit
- **Deployment**: Vercel
